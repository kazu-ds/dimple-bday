DIMPLE BIRTHDAY WEBSITE

Open index.html in a browser.

To personalize:
1. Replace the three cards and timeline text with your real memories.
2. Create an images folder and add photo1.jpg through photo6.jpg.
3. The letter is a starter draft — rewrite it with your own specific memories.
4. The whole site is static HTML/CSS/JS, so it can be hosted on GitHub Pages, Netlify, Vercel, etc.

The site is intentionally designed as a starting version: the next pass can make it much more "Dimple" once you give me your actual memories, photos, inside jokes, and last year's letter.
